# Правила игры IronLogic

IronLogic - игра-битва программируемых роботов.
Вы пишете программу поведения робота на Python, выбираете карту и соперников, запускаете бой.
Бой симулируется детерминированно, такт за тактом. Побеждает лучший код.

## Арена

- Прямоугольная сетка клеток. Размер по умолчанию: 1v1 = 24x24, до 4 роботов = 32x32, до 8 = 40x40.
- Граница поля - непроходимый камень (STONE).
- Типы клеток:

| Имя | Код | Поведение |
|---|---|---|
| EMPTY | 0 | Пустая клетка |
| STONE | 1 | Камень/стена, непроходим, останавливает снаряды |
| PIT | 2 | Яма: если робот въезжает - уничтожается |
| REACTOR | 3 | Реактор: взрывается при попадании, урон 40 в радиусе 1, цепная реакция |
| AMMO | 4 | Ящик с патронами: +5 (макс. 20), клетка становится пустой |
| RECHARGE | 5 | Розетка: +5 энергии за такт, пока робот стоит на ней |
| ROBOT | 6 | Робот (враг) |
| FRIEND | 7 | Робот своей команды (зарезервировано) |
| PROJECTILE | 8 | Летящий снаряд |
| UNKNOWN | 255 | Не вижу |

## Робот

- Занимает одну клетку, имеет направление N / E / S / W.
- 4 аппаратных слота (front, right, back, left): eye, cannon или empty.
- Радар (опционально): сканирует объекты в радиусе, тратит энергию.
- Характеристики:
  - Здоровье: старт 100; при 0 - робот уничтожен.
  - Энергия: старт 100; тратится на действия; при 0 - shutdown, робот не действует, пока не встанет на RECHARGE.
  - Патроны: старт 5, максимум 20; выстрел тратит 1.
  - Скорость (по числу пушек): 0-1 пушка - движение каждый такт; 2 пушки - каждые 2 такта; 3 - каждые 3 такта; 4 - неподвижен.

Энергозатраты: базовый расход 1/такт; движение 2; выстрел 3; радар 2/такт.

## Такт (порядок обработки)

1. Роботы по порядку id: если жив и не в shutdown - исполняется программа, выполняется одно действие.
2. Движение снарядов: 1 клетка за такт, попадания, взрывы реакторов.
3. Эффекты: расход энергии, подзарядка, проверка смертей.
4. Условия конца боя.

Движок полностью детерминирован: одинаковые входные данные дают побайтово одинаковый лог боя.

## Действия (одно за такт)

- move("forward" | "backward") - движение на 1 клетку.
- turn("left" | "right") - поворот на 90 градусов.
- shoot("front" | "right" | "back" | "left") - выстрел из пушки.
- wait() - пропустить такт.
- radar_on() / radar_off() - включить/выключить радар.

## Конец боя

- Победа: последний живой робот (last_standing).
- Лимит тактов (по умолчанию 10000): побеждает робот с наибольшим здоровьем; при равенстве - больше патронов, затем энергия, затем меньший id (time_limit).
- Ничья: все погибли одновременно (draw).

## Пресеты карт

- arena - открытая, мало камней;
- ruins - завалы камней, узкие проходы;
- ravine - коридоры из камней, ямы вдоль стен;
- junkyard - много реакторов и ям;
- symmetric_1v1 - зеркальная карта для честных дуэлей.

Карты генерируются детерминированно по seed. Инварианты: спавны на пустых клетках, из каждой пустой клетки достижимы розетка и ящик с патронами.
